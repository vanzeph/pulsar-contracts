# Pulsar family version pins (release lockfile input).
#
# Every Pulsar package is pinned to an anchored, public HTTPS git reference
# (commit hash until repositories cut vX.Y.Z tags). Install with:
#     pip install -r pulsar.constraints.txt          # the six packages
#     pip install -c pulsar.constraints.txt -e ...    # editable workspace
# See README.md in this directory for conventions and re-locking.

# NOTE on hash forms — pip compares direct references verbatim, so each
# line below keeps the exact form the family declares for that package:
# - pulsar-contracts is pinned at the SHORT commit 2e3e393, the exact
#   direct reference every downstream repository (core/data/exec/app)
#   declares in [project.dependencies]; pinning the same commit as a
#   40-char hash would conflict with those transitive requirements.
# - pulsar-core keeps the 40-char full hash pulsar-app's [project.dependencies]
#   declares (base dependency since the unified store, STORE1), while
#   pulsar-data/exec keep the 40-char hashes pulsar-app's [e2e] extra
#   declares, so `pip install -c pulsar.constraints.txt "pulsar-app[e2e]"`
#   also resolves verbatim.
# - pulsar-app/pulsar-ui have no in-family dependents; they carry full
#   hashes purely for explicitness.
