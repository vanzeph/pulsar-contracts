# Pulsar family version pins (release lockfile input).
#
# Every Pulsar package is pinned to an anchored, public HTTPS git reference
# (commit hash until repositories cut vX.Y.Z tags). Install with:
#     pip install -r pulsar.constraints.txt          # the six packages
#     pip install -c pulsar.constraints.txt -e ...    # editable workspace
# See README.md in this directory for conventions and re-locking.

# NOTE: contracts is pinned at f385fbd — the exact direct reference every
# downstream repository declares in its pyproject. pip compares direct
# references verbatim (full and short hashes of the same commit are NOT
# equal to it), and pinning any other commit fails resolution. Newer
# contracts main-head commits that only add repo tooling (like 5d28b2f,
# which added this directory) stay install-compatible with this anchor
# because they change no package code.
